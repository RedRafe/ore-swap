# Ore Swap

A lightweight utility mod for Factorio that allows you to quickly replace existing resource patches on the map with any target resource of your choice.

## Features

* **Target Resource Selector:** Click the **Ore Swap** shortcut button to open a clean GUI window and pick your desired target resource.
* **Direct Replacement:** Drag the selection tool over any resource patch to instantly convert all selected ores into your chosen target while preserving their original yield amounts and positions.
* **Persistent Selection:** Your chosen target resource remains saved until you clear or change it.

## How to Use

1. Click the **Ore Swap** icon on your shortcut bar.
2. Select your desired target ore from the resource picker window that appears.
3. Drag the **Ore Swap** selection tool across any ore patch you want to transform.
